# Third-party components

The vendored `third_party/nlohmann/json.hpp` is [JSON for Modern C++ v3.12.0](https://github.com/nlohmann/json/releases/tag/v3.12.0), Copyright (c) 2013-2025 Niels Lohmann. Its SHA-256 is `aaf127c04cb31c406e5b04a63f1ae89369fccde6d8fa7cdda1ed4f32dfc5de63`. The header carries MIT SPDX tags; the complete [MIT license](third_party/nlohmann/LICENSE.MIT) is copied from the [official v3.12.0 license](https://raw.githubusercontent.com/nlohmann/json/v3.12.0/LICENSE.MIT). Include that license and this notice with source and binary distributions.

The Steam authentication helper uses locally supplied Steamworks SDK headers, the 32-bit `steam_api.lib` import library, and Valve's `steam_api.dll` runtime. These Valve components are supplied separately and retain their applicable Valve/Steamworks terms; this project's notices grant no additional rights to them. The SDK headers and import library are build inputs and are not committed or packaged. [Valve's integration instructions](https://partner.steamgames.com/doc/sdk/api) identify the Steamworks API DLL as a redistributable and require it beside the executable or on its DLL search path. The local test package places it beside `steam_auth_helper.exe`; it also requires a running, signed-in Steam client.

The generated `steam_appid.txt` containing AppID 730 is a development configuration for this authorized local Legacy test. Valve documents it as a development aid and instructs developers to remove it when uploading a game to a Steam depot. This prototype is not a registered Steam product or a Steam depot release. No CS:GO engine DLLs, maps, models, textures, or other asset files are included in the repository or required by the protocol core.

[`dependencies.lock.json`](dependencies.lock.json) records the exact vendored JSON header, locally supplied Steamworks headers/import library, deployed Steamworks DLL, and observed build toolchain. It contains hashes and provenance, not Valve SDK or game file contents. Build-time use of the matching installation to generate schemas and integrity metadata is separate from runtime use of those derived metadata files.

Protocol metadata is derived from the user-provided matching Legacy installation. The historical public SteamTracking protobuf baseline is commit `4ed721cdcc8d828e5dcac3b8d86556e941c804a2`; the installed descriptors are the authority for this profile.
